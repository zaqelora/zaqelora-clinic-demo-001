# ZAQELORA Clinic Demo 001

A responsive, premium-corporate demonstration website for a fictional general physician clinic.

## Demo identity
- Clinic: Aarogya Family Clinic (fictional)
- Doctor: Dr. Ananya Mehta (fictional profile)
- Location: Sample Address, Baner Road, Pune, Maharashtra 411045 (placeholder)
- Contact: +91 00000 00000 / hello@example.invalid (placeholders)

## Contents
- `index.html` — complete single-page clinic website
- `assets/css/style.css` — responsive styling and visual identity
- `assets/js/main.js` — mobile navigation, date validation and demo-only enquiry interaction

## Run locally
Open `index.html` in a modern browser. No build tools, Node.js or server are required.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `zaqelora-clinic-demo-001`.
2. Upload the contents of this folder (not the outer folder itself) to the repository root.
3. In repository Settings → Pages, choose deploy from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish.

## Before showing a real clinic
Replace all fictional details and imagery with clinic-approved material:
- Clinic name, logo, address, phone, email, hours and map location
- Doctor names, qualifications, registrations, photographs and biographies
- Actual services and appointment instructions
- Privacy notice and terms, after appropriate review

## Important demo limitations
- This is a visual and interaction prototype, not a production patient-management system.
- The appointment form validates fields in the browser and displays a demo confirmation only. It does not transmit, save or book an appointment.
- Phone and email details are placeholders. No real WhatsApp or map destination is configured.
- Images are loaded from Unsplash URLs and therefore require an internet connection. Replace with properly licensed, clinic-approved images before commercial deployment.
- Do not enter real patient or health information into this demo.
- Do not represent the fictional clinic, doctor, address, services or credentials as real.
