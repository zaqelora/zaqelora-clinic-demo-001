# ZAQELORA Clinic Demo 001 — Enhanced Edition

Premium corporate demonstration website for **Aarogya Family Clinic**, a fictional general physician clinic.

## Included sections
- Premium hero and clinic identity
- Clinic introduction and care principles
- General consultation, preventive health, chronic care and family health
- Fictional doctor profile
- Patient visit guide
- Emergency-care disclaimer
- Clinic hours, sample contact details and illustrative location panel
- Appointment enquiry form (client-side demo only)
- Responsive mobile navigation and layouts
- SEO and social-sharing metadata
- Accessibility-conscious labels, focus states and reduced-motion support

## Files
- `index.html`
- `assets/css/style.css`
- `assets/js/main.js`

## Run
Open `index.html` in a modern browser. No Node.js, build step or backend is required.

## Publish with GitHub Pages
1. Create a public repository, e.g. `zaqelora-clinic-demo-001`.
2. Upload the contents of this folder to the repository root.
3. In Settings → Pages, select Deploy from a branch, branch `main`, folder `/(root)`, then Save.
4. Wait for GitHub Pages to publish.

## Before showing to a real clinic
Replace and verify:
- Clinic name, logo, address, phone, email, timings and map location
- Doctor's name, qualifications, registration details, photo and biography
- Actual services, scope, availability and appointment instructions
- Privacy notice, terms, consent language and data handling arrangements
- All photographs with properly licensed, clinic-approved images

## Demo limitations
- This is a static website prototype, not a production clinic-management system.
- The appointment form validates fields and shows a local demo confirmation only. It does not transmit, store or book appointments.
- All clinic, doctor, qualification, location, schedule and contact information is fictional or placeholder content.
- Images load from Unsplash and require internet access. Replace with licensed and approved images for a real deployment.
- Do not enter real patient information.
- Do not present the fictional clinic or doctor as real.
